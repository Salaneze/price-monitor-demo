# Мониторинг цен — демо-парсер

Обходит каталог интернет-магазина по расписанию, хранит цены и остатки,
выгружает таблицу в Excel или Google Sheets и пишет в Telegram, когда что-то
изменилось: подешевело, подорожало, закончилось, снова в наличии, новинка,
снято с продажи.

Для демонстрации парсит [books.toscrape.com](https://books.toscrape.com/) —
учебный магазин, который сделан специально для тренировки парсеров. Под
реальный сайт меняется только `monitor/scraper.py`: селекторы страницы
категории и карточки товара. Хранилище, сравнение, таблицы и уведомления
остаются как есть.

## Что умеет

- **Без дублей.** Товар опознаётся по артикулу, а не по ссылке. Магазин
  перенёс товар в другую категорию и сменил URL — в таблице это та же строка,
  а не новая.
- **История цен.** Отдельный лист: когда и сколько стоил каждый товар. Строка
  появляется только при изменении цены или остатка, так что лист не пухнет
  от одинаковых записей каждые 6 часов.
- **Уведомления по делу.** Первый запуск молчит (иначе весь каталог пришёл бы
  «новинками»). Товар не считается снятым с продажи, если его страница просто
  не открылась из-за сбоя сети или его категорию сейчас не обходили.
- **Бережно к сайту.** Не больше 5 одновременных запросов, повтор с паузой при
  ошибках сервера, понятный User-Agent.
- **Деньги без округлений.** Цены хранятся как `Decimal`, а не `float` —
  51.77 не превращается в 51.769999.

## Запуск

```
python -m venv .venv
.venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env          # Linux/macOS: cp
python -m monitor               # один обход
python -m monitor --every 6h    # обход каждые 6 часов
```

Результат — `data/prices.xlsx`, листы «Товары» и «История цен».

Посмотреть уведомления без ожидания: учебный сайт цены не меняет, поэтому
`demo_shift.py` «откатывает» сохранённый снимок, и следующий обход находит
изменения.

```
python -m monitor
python demo_shift.py
python -m monitor      # 3 × «Подешевело», 1 × «Снова в наличии»
```

## Настройки (`.env`)

| Переменная | Что | По умолчанию |
|---|---|---|
| `CATEGORIES` | пути категорий через запятую; пусто — весь каталог | две категории |
| `CONCURRENCY` | одновременных запросов | 5 |
| `TG_TOKEN`, `TG_CHAT_ID` | бот и чат для уведомлений | выключено |
| `GSHEET_ID`, `GSHEET_CREDENTIALS` | ID таблицы Google и JSON сервисного аккаунта | выключено |

Google Sheets: создать сервисный аккаунт в Google Cloud, скачать JSON-ключ,
выдать почте аккаунта доступ «Редактор» к таблице, `pip install gspread`.

## Расписание на сервере

`--every` подходит для запуска в фоне. На VPS надёжнее cron — он переживёт
перезагрузку:

```
0 */6 * * * cd /opt/price-monitor && .venv/bin/python -m monitor >> monitor.log 2>&1
```

## Тесты

```
python -m unittest
```

Разбор страниц проверяется на сохранённых HTML из `tests/fixtures`, без сети.
Сравнение снимков — на подставных данных: подешевело, подорожало,
закончилось, вернулось, пропало при сбое сети, повторный обход без дублей.

## Структура

```
monitor/
  scraper.py   страницы категорий и карточки товаров -> Product
  store.py     SQLite: товары, история, поиск изменений
  export.py    Excel и Google Sheets
  notify.py    сообщения в Telegram, разбивка длинных списков
  config.py    настройки из .env
demo_shift.py  сдвиг снимка для демонстрации уведомлений
```

## Под заказ

Типичная доработка под конкретный магазин — 1-2 дня: селекторы под вёрстку,
нужные поля (бренд, размеры, продавец), фильтр уведомлений (например, только
скидка больше 10 %). Сайты с защитой от парсинга обсуждаются отдельно.
